# Project rules

- Keep this project dependency-free; the app should run by opening `index.html` directly.
- Keep the quiz self-contained in `index.html` unless a change clearly needs another file.
- Preserve responsive layouts, accessible keyboard and screen-reader behavior, and light/dark theme support.
- Respect reduced-motion preferences and keep feedback understandable without color alone.
- After UI or behavior changes, verify the quiz in the integrated browser, including answer feedback and the results/restart flow.
